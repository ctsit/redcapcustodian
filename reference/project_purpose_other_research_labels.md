# project_purpose_other_research_labels

A tibble project purpose other IDs and labels that reflect their meaning
as used in the \`purpose_other\` column of the \`redcap_projects\` table

## Usage

``` r
project_purpose_other_research_labels
```

## Format

A data frame with 5 rows and 2 variables:

- `id`:

  double primary key

- `project_purpose_other_research`:

  character redcap purpose other research
