# Get the value from the redcapcustodian.env environment

Get the value from the redcapcustodian.env environment

## Usage

``` r
get_package_scope_var(key)
```

## Arguments

- key:

  The identifying string to lookup

## Examples

``` r
if (FALSE) { # \dontrun{
  get_package_scope_var("hello")
} # }
```
