# project_status_labels

A tibble of project status IDs and project statuses that reflect their
meaning as used in the \`status\` column of the \`redcap_projects\`
table

## Usage

``` r
project_status_labels
```

## Format

A data frame with 4 rows and 2 variables:

- `id`:

  double primary key

- `project_status`:

  character redcap project status
