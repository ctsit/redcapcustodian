# Provides a list of table names which have schema and data files as part of the package

Provides a list of table names which have schema and data files as part
of the package

## Usage

``` r
get_test_table_names()
```

## Value

A list of table names which have schema and data files as part of the
package

## Examples

``` r
get_test_table_names()
#> [1] "redcap_projects"         "redcap_user_information"
```
