# user_rights_test_data

A named list of dataframes used to test the functions written to manage
user rights

## Usage

``` r
user_rights_test_data
```

## Format

A named list of 3 dataframes:

- `redcap_user_information`:

  REDCap Core table

- `redcap_user_rights`:

  REDCap Core table

- `redcap_user_roles`:

  REDCap Core table
