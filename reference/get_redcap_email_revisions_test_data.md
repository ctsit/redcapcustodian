# get_redcap_email_revisions_test_data

A list of test inputs and outputs for get_redcap_email_revisions

## Usage

``` r
get_redcap_email_revisions_test_data
```

## Format

A list of 3 tibbles:

- `bad_redcap_user_emails`:

  tibble of bad email address and redcap usernames

- `person`:

  tibble of corrected email addresses and the corresponding usernames

- `output`:

  tibble of output from get_redcap_email_revisions
