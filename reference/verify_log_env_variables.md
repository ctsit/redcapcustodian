# Verifies all required environment variables are set. Returns an empty list if all necessary environment variables are set, returns a list of errors otherwise.

Verifies all required environment variables are set. Returns an empty
list if all necessary environment variables are set, returns a list of
errors otherwise.

## Usage

``` r
verify_log_env_variables()
```

## Value

A list of \`error_list\` entries.

## Examples

``` r
if (FALSE) { # \dontrun{
 verify_log_env_variables()
} # }
```
